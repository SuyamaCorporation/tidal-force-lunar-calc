# Tidal Force & Lunar Phase Calculator

## 概要
月齢（0〜29.5日）スライダーで月の満ち欠けアイコン・潮汐力の大きさ・満潮/干潮の相対時刻を棒グラフで表示する天文教育ツール。

## 機能
- 月齢スライダー（0〜29.5日）
- 月相の視覚的描画（canvas）
- 8段階の月相名称表示（新月〜三日月など）
- 潮汐力の相対的強さバー表示
- 満潮・干潮高さの計算（相対値）
- 潮汐タイプ判定（大潮/小潮）
- 月周期全体の潮汐力推移グラフ

## 使い方
スライダーで月齢を調整すると月相が更新されます。新月と満月（大潮）では潮汐力が最大になり、半月（小潮）で最小になる様子が確認できます。
